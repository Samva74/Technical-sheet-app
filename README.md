# Technical Sheet App V6

Version compacte pour écran de PC portable, avec traductions FR/EN/PT, images multiples du produit, alignement des composants et marquages, nouvelle section Contre-boîte conditionnelle, filtre Documents Contre-boîte, PDF et ZIP.

Les fichiers sont enregistrés localement en base64. Pour les gros fichiers et le multi-utilisateur, utiliser Supabase Storage.
